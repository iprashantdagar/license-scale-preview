# Publish checklist

## Site

- [ ] Five pages exist at `/`, `/apply`, `/results`, `/careers`, `/thank-you`.
- [ ] Home is set as the site's default page.
- [ ] Domain and SSL are connected.
- [ ] Page background is `#0B0A12` with no white builder gutters.
- [ ] Poppins loads at all required weights.
- [ ] Favicon and social image are configured.

## Navigation and content

- [ ] Logo returns to `/`.
- [ ] Homepage anchor links scroll to the correct sections.
- [ ] Results, Careers, and Apply links use the GHL pages.
- [ ] Mobile navigation opens, closes, and remains above page content.
- [ ] Privacy Policy and Terms links are correct.
- [ ] There are no duplicate IDs after hybrid blocks are assembled.

## Media and interactions

- [ ] Wistia hero videos load and play.
- [ ] YouTube thumbnails load and videos play inline.
- [ ] Results carousel arrows, dots, swipe, and keyboard controls work.
- [ ] Community images open and close in the lightbox.
- [ ] FAQ items open and expose the correct answer.
- [ ] Reduced-motion mode does not hide content.

## Forms and automation

- [ ] Static HTML application form has been replaced with the native GHL form.
- [ ] Required fields and validation work.
- [ ] Submission creates or updates one contact.
- [ ] Custom fields, source, and role are stored.
- [ ] Workflow tags and internal notification fire once.
- [ ] Redirect reaches `/thank-you` without personal data in the URL.

## Responsive QA

- [ ] 1440px desktop
- [ ] 1024px laptop/tablet landscape
- [ ] 768px tablet portrait
- [ ] 390px mobile
- [ ] 320px small mobile
- [ ] No unintended horizontal scrolling
- [ ] No clipped headings, buttons, cards, menus, or form fields
- [ ] Tap targets are at least 44px

## SEO and compliance

- [ ] Unique page title and meta description on every page.
- [ ] One H1 per page.
- [ ] Images have useful alt text.
- [ ] Tracking scripts and consent settings match the business's requirements.
- [ ] Test pages are noindexed until launch.
- [ ] Final pages are indexable only after approval.

## Template handoff

- [ ] Save navigation and footer as Global Sections.
- [ ] Name native sections consistently.
- [ ] Remove abandoned test pages and duplicate tracking snippets.
- [ ] Create the GHL Website/Funnel share link or agency snapshot.
- [ ] Import the share/snapshot into a clean sub-account and repeat smoke tests.
